## 4. Восстановление после сброса песочницы (15 минут)

1. Распакуй zip → `sha256sum git_ssh_wrapper_pro.py robot-seismos` (сверь с §3).
2. `pip install paramiko`
3. Ключ в два места: `mkdir -p ~/keys && cp robot-seismos ~/keys/ && chmod 600 ~/keys/robot-seismos`
4. Обёртка: `chmod +x git_ssh_wrapper_pro.py` + экспорты `GIT_SSH`, `GIT_SSH_KEY`,
   **`GIT_SSH_VARIANT=ssh`** (без него git падает «ssh variant 'simple' does not
   support setting port» — проверено e2e 08.10; пути абсолютные — Шаг 3 README).
5. Remote: `git remote set-url origin ssh://git@ssh.github.com:443/gabbardtools-a11y/seismos.git`
6. Тест: `git ls-remote origin` → список рефов = жив.
7. `git fetch origin && git rebase origin/main` → работаешь.
8. Читай worklog семьи и этот PACKET — контекст восстановлен.

## 6. Грабли, на которые наступали

- В песочнице **нет ssh-бинарника** — git только через обёртку на ssh.github.com:443.
- Push «висит»? Ты не через обёртку или не тот ключ. Проверь экспорты GIT_SSH/GIT_SSH_KEY.
- Рестарт песочницы = чистые ~/.ssh и ~/keys — ключ держи в двух местах.
- Изменение файлов в public/ требует перезапуска pm2-процесса (кэш листинга) —
  но pm2 трогает Ибро, просто знай и предупреди.
- PDF публикации ведут на akbiev.ru (внешний, WordPress) — НЕ «чинить», это
  научные статьи; wp-след в HTML не улика аффилированности.
