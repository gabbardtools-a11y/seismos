# Skill: News Headlines Parser — парсинг заголовков о землетрясениях

> Автоматический сбор и дедупликация заголовков новостей о землетрясениях
> с 4 русскоязычных источников. Используется в разделе «Новости» сайта СРОСС®.

## Когда применять

- Нужна лента свежих новостей о землетрясениях в России и мире
- Нужны только **заголовки** (без полного текста статей — это обход
  авторских прав)
- Нужна **дедупликация** — одна и та же новость может выйти в нескольких СМИ,
  выбирается самый длинный (наиболее информативный) заголовок
- Обновление — **раз в сутки** (не чаще, чтобы не нагружать источники)

## Источники

| Ключ | Название | URL | Метод |
|------|----------|-----|-------|
| `iz` | Известия | https://iz.ru/tag/zemletriasenie | page_reader (HTML) |
| `rt` | RT на русском | https://russian.rt.com/tag/zemletryasenie | page_reader (HTML) |
| `lenta` | Lenta.RU | https://lenta.ru/rss | RSS (XML) |
| `vesti` | Вести.RU | https://www.vesti.ru/proisshestviya/stikhiinye-bedstviya/zemletryaseniya | page_reader (HTML) |

> **Почему 3 из 4 через page_reader, а не RSS?**
> У iz.ru и rt.com tag-specific RSS возвращают HTML 404. У Вестей RSS нет
> вообще. page_reader от z-ai обходит блокировки и отдаёт SSR-разметку.

## Пайплайн

```
[Источники] → fetch (RSS / page_reader) → parse HTML/XML → фильтр earthquake
   → dedup (Jaccard ≥ 0.55) → выбор самого длинного → JSON → /news page
```

### Шаг 1. Fetch

- **RSS** (Lenta): прямой HTTP через `urllib.request` с User-Agent.
- **HTML** (iz, rt, vesti): через `z-ai function -n page_reader` — обходит
  блокировки по IP, корректно обрабатывает SSR-разметку.

### Шаг 2. Парсинг

**RSS** (`parse_rss`): `xml.etree.ElementTree` → `<item>` → `<title>`, `<link>`, `<pubDate>`.

**HTML** (`parse_html`) — 4 стратегии поиска заголовков:

1. `<a href="...">длинный текст</a>` — основной паттерн ссылок
2. `<h2>/<h3>/<h4>` — заголовки внутри карточек
3. JSON-встроенные данные: `"title":"..."`, `"headline":"..."`, `"name":"..."` —
   Vue/SSR-сайты сериализуют данные в inline-скрипты
4. `<meta property="og:title" content="...">` — fallback на канонический заголовок

URL нормализуется к абсолютному через `base` источника.

### Шаг 3. Фильтр earthquake-темы

Только заголовки, содержащие хотя бы одно из:
```
землетряс, сейсмо, толчок, магнитуд, рясени, эпицентр, подземн
```

### Шаг 4. Дедупликация

- **Токенизация**: lowercase → убрать пунктуацию и цифры → множество слов
- **Похожесть**: коэффициент Жаккара на множествах токенов
- **Порог**: `0.55` — заголовки считаются дублями если ≥55% общих слов
- **Группировка**: сортируем по длине убыв, первый в группе = эталон
- **Выбор**: из каждой группы берём самый длинный заголовок (пожирнее)
- **Сохраняем**: `all_sources` — список всех источников, где встретилась новость
  + `duplicate_count` — сколько раз встретилась

### Шаг 5. Сохранение

`src/data/news-headlines.json`:
```json
{
  "fetched_at": "2026-10-09T...Z",
  "total_raw": 25,
  "total_unique": 23,
  "sources": [{"key": "iz", "name": "Известия"}, ...],
  "news": [
    {
      "title": "...",
      "url": "https://...",        // может быть пустым
      "source": "iz",               // источник самого длинного заголовка
      "all_sources": ["iz", "rt"],  // все источники где встретилась
      "duplicate_count": 2,
      "date": ""                    // pubDate из RSS, если есть
    }
  ]
}
```

## Страница `/news`

`src/app/news/page.tsx` — server component, читает JSON напрямую через `import`.
Каждая новость — карточка:
- Заголовок (кликабельный если есть URL)
- Бейджи всех источников где встретилась
- Счётчик «в N источниках» если дублей > 1
- Ссылка «источник →» на оригинал
- Дисклеймер про авторские права

## Англицизмы и ИИ-следы

**Англицизмы:** в заголовках о землетрясениях технические термины
(магнитуда, PGA, MSK-64) — нормальны и нужны. Проверяем только
неоправданные англицизмы (типа «сейшн», «митинг»). Поскольку мы парсим
**только заголовки** из русскоязычных СМИ, риск англицизмов минимален.

**ИИ-следы:** так как мы **не делаем рерайт** (только оригинальные заголовки),
проверка на ИИ-следы не нужна.

**Китайские иероглифы:** регулярное выражение CJK-диапазона на случай если
парсер зацепит мусор:
```python
re.search(r'[\u4e00-\u9fff]', title)  # CJK Unified Ideographs
```

## Известные ограничения

1. **URL не всегда извлекается** — если заголовок найден в JSON-данных без
   соседнего URL, ссылка будет пустой. На странице такие новости показываются
   без ссылки, только с бейджем источника.

2. **Вести.ru** — иногда отдают только `og:title` страницы-раздела
   («Землетрясения в мире: последние новости на сегодня»), а не отдельные
   новости. Это ограничение их SSR-разметки.

3. **page_reader timeout** — иногда z-ai function медленно отвечает. Скрипт
   использует `timeout=90` секунд на каждый источник.

4. **Блокировки по IP** — page_reader обходит, но при частом запросе
   источник может временно заблокировать. Поэтому обновление — раз в сутки.

## Расширение

Чтобы добавить новый источник:
1. Добавить запись в `SOURCES` (с `rss` или `page_url`)
2. При необходимости — написать экстрактор в `parse_html` под специфичную
   разметку
3. Запустить скрипт — проверить что заголовки извлекаются
4. Добавить источник в `SOURCE_NAMES` и `SOURCE_URLS` на странице `/news`
